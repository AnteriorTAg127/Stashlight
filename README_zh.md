# Stashlight

**别再像疯子一样翻箱倒柜了——一秒找到你藏起来的战利品。**

**Stashlight** 是一个 Fabric 模组，它会自动索引你打开过的每一个容器，让你可以跨维度瞬间搜索世界中的物品——甚至包括**潜影盒**、**收纳袋**和嵌套容器内的物品。

可作为**纯客户端**模组在单人游戏和客户端模式下使用，也可作为**双端**模组运行：安装在服务端时，它能主动扫描并向客户端推送容器数据，无需玩家逐个打开容器。

## 功能

- **全地图即时搜索**
  跨维度定位所有已索引容器中的物品。

- **嵌套容器索引**
  缓存嵌套物品栏，支持搜索潜影盒和收纳袋内部的物品。

- **增强预览**
  完全兼容 **ShulkerBoxTooltip**，在搜索菜单中直接预览物品。

- **广泛的容器支持**
  兼容箱子、木桶、潜影盒、漏斗、投掷器、发射器以及大多数带有物品栏的模组方块实体\*。

- **附魔搜索与筛选**
  切换到附魔搜索模式，按附魔类型筛选，用 AND/OR 逻辑组合多个附魔词条，并按等级区间缩小结果范围。支持按附魔词条数量排序。

- **多层视觉高亮**
  点击搜索结果即可高亮容器：
  - **方块线框** — 容器方块的 X 光线框
  - **GUI 格子高亮** — 高亮打开容器内的特定格子
  - **嵌套盒子高亮** — 高亮容器内的潜影盒/收纳袋
  - **世界光柱** — 信标式光柱，可穿墙可见

  Shift+点击可高亮多个结果，或用 ✦ 按钮高亮全部匹配结果。

- **服务端扫描（可选）**
  安装在服务端时，Stashlight 可扫描每位玩家周边已加载的容器并主动推送更新——无需手动打开容器。支持增量同步（仅发送变更/移除的容器）和维度切换自动推送。

- **跨维度追踪**
  追踪主世界、下界、末地以及模组维度中的容器\*。

- **客户端自动索引**
  可选的客户端自动扫描器，按可配置间隔索引已加载区块中的周边容器——适用于单人游戏或服务端未安装 Stashlight 的情况。

- **可配置的高亮设置**
  独立开关每种高亮层，自定义颜色，调整高亮时长（1–60 秒），启用/关闭脉冲闪烁效果。

- **工作台合成（v1.5）**
  打开搜索界面的「合成」页，基于原版配方书列出已解锁配方（可合成亮显、缺材料置灰），支持配方搜索与「仅显示可合成」过滤。点击配方查看 3x3/2x2 合成预览与实时消耗表（需要/背包有/范围内有/需取），输入数量后**一键拿取并合成**：自动从可触碰范围内箱子补齐缺失材料（modded/原版服双模），再按原版配方书方式放置并批量合成，目标精确停止不超量。可触碰范围内有工作台时合成 3x3 全配方，无工作台时用背包 2x2 合成格。
  合成页左上「周边库存」区显示可触碰箱子内的物品，点击可自动匹配以它为原料的配方。

- **双语支持（EN / 中文）**
  完整的英文和简体中文本地化。

<br/>

<sub>\* _模组容器和维度未经测试，但预期可正常工作_</sub>

## 用法

按**小键盘 5** 打开搜索菜单（可在 Minecraft 控制设置中修改按键）。

### 搜索模式

- **物品模式** — 按物品名称搜索。结果显示持有该物品的所有容器及格子级位置信息。
- **附魔模式** — 按附魔搜索。选择一个或多个附魔词条，设置等级范围，用 AND/OR 逻辑组合。在搜索框中使用 `@ench:` 前缀可快速进行附魔查询。

### 数据源

当服务端安装了 Stashlight 时，可切换数据源：
- **本地** — 仅你自己打开过的容器
- **服务端** — 仅服务端扫描的容器
- **合并** — 两者合并

使用 ↻ 刷新按钮请求新的服务端扫描。**Shift+点击**刷新按钮可强制全量扫描（跳过增量同步）。

### 高亮

点击任意搜索结果即可在世界中高亮容器。⚙ 按钮打开高亮设置界面，可开关各高亮层、设置颜色和调整时长。

## 服务端配置

安装在服务端时，Stashlight 会生成 `config/stashlight-server.json`，包含以下配置项：

| 模块 | 主要设置 |
|------|---------|
| `scan` | `maxRadius`、`radiusUnit`（blocks/chunks）、`maxContainersPerRequest`、`containersPerTick`、`maxDepth`、`sameDimensionOnly` |
| `rateLimit` | `minRequestIntervalTicks`、`bucketCapacity`、`refillTicks` |
| `push` | `enabled`（进服推送 + 增量同步）、`radius` |
| `permission` | `requireOp`、`permissionNode`、`respectClaims` |
| `limits` | `maxResponseBytes` |

使用 `/stashlight reload`（权限等级 2）可热重载配置，无需重启服务器。
